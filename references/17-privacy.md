# 本地隐私检查与脱敏

把材料交给模型、放进提示词或提交仓库前，先在本机检查并生成脱敏副本。此工具只做确定性的形式匹配；通过检查不代表材料已匿名化，仍须人工复核。不要把真实秘密粘贴到命令行参数或终端日志。

在 prompt-vault 目录运行，需要支持 `node:test` 和 `TextDecoder` 的现代 Node.js，不安装额外依赖，不联网，不读取环境变量或凭据配置：

```powershell
node scripts/privacy.cjs --check materials.txt
node scripts/privacy.cjs --redact materials.txt --out materials.redacted.txt
node --test tests/privacy.test.cjs
```

`--check` 只读输入。发现待处理项时退出码为 `1`，未发现时为 `0`；参数、路径、编码或写入错误统一返回 `2`。标准输出是 JSON，只有类型、数量、位置和 `manual_review_required: true`，不含匹配原文、输入内容的 hash 或文件路径。错误也不回显输入、路径或系统异常。不要把工具内部调试输出改为打印原始匹配值。

`--redact` 创建全新 UTF-8 文件，标准输出只有数量摘要和人工复核标志，不打印脱敏正文。拒绝覆盖输入或任何既有文件，拒绝硬链接输入、符号链接和含符号链接或 junction 的路径。只接受正常 UTF-8 文本，拒绝非法编码及常见二进制控制字符。工具先扫描生成内容，再把完整结果写入同目录独占临时文件并再次扫描，最后用原子、禁止覆盖的文件链接操作发布并清理临时文件；验证失败不会发布输出。目标文件系统必须支持硬链接，且执行期间目录不应由不可信进程并发修改。工具无法回滚磁盘损坏、断电或异常权限变化造成的文件系统故障。

## 检测范围

- 邮箱、连续的中国大陆手机号码（可带 `+86` 或 `86` 前缀）、15 位或 18 位身份证号码形式、`sk-` 开头且后续至少 20 个字母/数字/下划线/连字符的 token。
- 有明确标签的姓名、住址、病历号、学号、密码及 token。支持 JSON 的单双引号键值、环境文件的 `KEY=value`、中文冒号或英文冒号。支持的键包括 `姓名`、`患者姓名`、`name`、`full_name`、`住址`、`地址`、`家庭住址`、`address`、`病历号`、`medical_record`、`medical_record_number`、`学号`、`student_id`、`password`、`密码`、`token`、`令牌`；英文键不区分大小写。
- 无引号标签值按行、逗号、分号、右花括号或中文句号分隔；有引号的值保留外围引号。标签包含嵌套格式或多字段未用分隔符时，应先人工检查字段边界。这里不是完整 JSON、YAML 或 shell 解析器。

不校验身份证校验位、手机号码是否分配或 token 是否有效；也不识别全部姓名和地址。自由叙述中的人名、未标注地址、分隔书写的手机号、机构内部标识、其他国家证件、图片、附件及其他密钥格式都可能遗漏。数字串形式也可能误报。标签字段含任务数据时，整个字段值可能被替换，须按原材料核对。

支持 Markdown 加粗标签及以竖线分隔的行内字段；空标签不跨行吞掉下一行。JSON 中数字等原始类型的标识字段会替换为带引号的字符串占位符，以保持 JSON 可解析；该字段类型会改变，不能再用于原标识的计算或校验。此工具仍不是完整结构化数据解析器。

`[REDACTED_EMAIL_1]` 等工具占位符，以及完整的 `【必填：匿名患者】` 等字段占位符不会被重复标记；占位符里面仍含邮箱、手机或长 token 等可识别内容时，工具仍会扫描该内容。重复出现的完全相同值在同一次脱敏中使用同一个占位符，跨类型时沿用首次类型；已有占位符编号被保留，新编号继续递增。映射仅在内存中存在，不保存原文映射表，也不生成原文指纹。

年龄、日期、剂量、单位、检验值、成绩等未命中规则的文本逐字保留。自行检查脱敏副本是否仍能支撑原任务，尤其是医疗材料的数值、单位、时间关系和必要上下文；不得为了脱敏而虚构数据。

## 模块接口

```javascript
const {scan, redact} = require('./scripts/privacy.cjs');
const findings = scan(text); // [{kind, start, end}]；不提供 value
const result = redact(text); // {text, counts, manual_review_required: true}
```

`start`、`end` 是 JavaScript 字符串 UTF-16 索引，采用左闭右开区间，可用于本地编辑器定位。`counts` 按类型计算出现次数，不是不同值数量。`redact` 返回的 `text` 是脱敏正文，仍可能包含未识别信息；模块调用者应限制该正文的传播。重新扫描只证明输出未再命中这些规则，不能替代人工复核。
