# Prompt Vault — 任务提示词模板库

覆盖 **12 大类、119 个**高质量提示词模板的 skill。针对具体任务（写论文、写代码、做产品、写法律文书、解读体检报告、备课……）给出**可复制的提示词**，你复制后改几个字段就能用。

## 怎么用

1. 说「给我一个提示词 + 你的任务」，或直接描述任务；
2. 技能按任务选中模板，给出可复制的提示词；
3. 复制到对话框，把 `【必填：xxx】` 占位符改成你自己的内容；
4. 发给 AI。

也可以说「帮我诊断这段提示词」「这段提示词效果不好」，让技能诊断和改进已有提示词。

## 设计原则

- **最小改动可用**：默认争取只改 1–2 个字段；
- **三级占位符**：必填 / 默认（不符再改）/ 材料（可留空）；
- **材料三态**：有材料 → 基于材料执行；缺材料有工具 → 先取材料；无材料 → 只给框架；
- **证据驱动**：数量服从证据，不为凑数编内容；
- **本地隐私**：合同、病历等材料先本地脱敏再交给模型。

## 维护

- `templates.json` 是模板元数据（名称、档位、材料、联网、降级）的唯一编辑入口；
- 提示词正文在 `references/*.md`，通过 `<!-- template: key -->` 稳定锚点关联；
- 改完运行 `node scripts/catalog.cjs --write` 同步，`node scripts/catalog.cjs --check` 校验；
- 字段说明与新增方法见 `references/16-catalog.md`。
